[05]What you get

One export. Ready to use.

One zip, made in your browser. Select the parts you want.

  • Design tokens

    In the DTCG standard, for light, dark and 3 density modes.

  • Ready code

    HTML, CSS and JS that opens in any browser. No build step.

  • Brand guideline

    A guide for your team, and a part written for AI coding tools. It follows the open DESIGN.md format.

  • Docs page

    One HTML page with live samples of your system.

  • Font guide

    Each font, its license and how to add it.

[08]FAQ

Short answers.

More questions about export, AI and privacy are on the FAQ page.

Read all questions
Do I need design skills?
No. You can start with images, words or a list of options. The app sets the values and checks contrast. Designers can use the Advanced view to edit each token.
I have no moodboard. Can I still use it?
Yes. Use the guided options: style, vibe, theme, emotion, density, corners, mode and brand color.
What do I get when I export?
One zip with design tokens (DTCG JSON), a ready HTML/CSS/JS codebase, a guideline file (DESIGN.md) and an HTML docs page.
Does it work with AI coding tools?
The guideline file (DESIGN.md) has a part for AI coding agents. It gives exact token names, class names and short rules.
Where is my data?
You can start with no account. Your work then stays as one draft in your browser. To save your projects and open them on any device, sign in with a free account. We never use saved projects to train our models. You can delete a project or your account at any time.
